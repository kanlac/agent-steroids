## 报告模板

用于输出 VPS / 机场节点质量评估报告。根据实际权限删减不可测项目；不可测要写“未测/无权限”，不要推断。

### 基本信息

| 项目 | 内容 |
|---|---|
| 测试时间 | YYYY-MM-DD HH:mm 时区 |
| 测试位置/网络 | 例如天津电信、公司宽带、移动热点 |
| 测试对象 | VPS 名称 / 机场节点名称 |
| 节点类型 | 源 IP 直连 / CDN 中转 / 商业机场 |
| 是否可登录服务端 | 是 / 否 |
| 测试限制 | 缺少哪些权限、工具、晚高峰数据 |

### 结论

写清楚：

- 适合：例如主力代理、备用、下载、网页、实时交互、Google 服务。
- 不适合：例如晚高峰主力、Google 服务、低延迟场景。
- 关键风险：例如 Google 地理误判、源 IP 被墙、去程普通线路、单线程吞吐差、无法换 IP。
- 购买建议：续费 / 不续费 / 只做备用 / 换供应商。
